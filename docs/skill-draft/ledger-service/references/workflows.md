# 业务工作流

## 记一笔

取得账本与账户 ID；已知用户明确指定的账户可直接匹配。输入金额以字符串传入，使用账户结算币；商家原币不同则同时记录原币与实际扣款。日期按账本时区解析。

调用 ledger_preview_transaction；检查金额、分类、汇率源时间和 warnings。若旧汇率需要选择，向用户说明具体报价时间与选项。授权明确且预览一致，调用 ledger_create_transaction，保留返回的 operationId / transactionId。

例：“今天用港币现金买午餐 28 港币”是 HKD 28 的 expense。它不授权更改现金账户的币种或创建额外账户。

## 转账与退款

转账需要源 / 目标账户及各币种实际金额；不能猜测外汇点差。手续费独立列支。两账户必须同一账本，服务端事务保证共同完成。

退款先读取原交易和可退余额，指定到账账户。部分退款关联原交易，由服务端抵减支出；不自行新建收入。

## 查询与订阅

优先聚合接口，保留请求期间和 valuationMode。订阅月均费用是预测，与已发生支出分开。没有实际付款事实不创建 payment。

新增订阅需金额、币种、周期、锚定日期、账户；提醒需通道和提前量。先用 ledger_preview_subscription / ledger_preview_reminder 展示未来日期，再按已有授权提交。个人微信与企业微信是不同 channel，不能替换用户指定渠道。

## 故障处理

401 / 403：说明认证或权限问题，不尝试绕过。
412：读取当前版本并重新预览，冲突事实交给用户决定。
429：尊重 Retry-After，限制重试。
网络未知结果：保留幂等键，通过 operation 状态核查；无法确认时明确说“结果待确认”。
导出任务 202：给出任务状态，完成后才能提供下载，不编造文件。
