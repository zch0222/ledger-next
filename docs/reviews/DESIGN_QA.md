## v0.2 · ECharts 与动效复核

根据用户要求，原型图表改为本地 Apache ECharts 6.0.0：渐变支出折线、收支对比柱形、分类条形和支出环图。增加错峰入场、数据过渡、预算进度与弹层轻动效。此处仍为设计原型，未实现 Next.js 产品。

已用 Playwright / Microsoft Edge 复核：

- 7 视图 × 5 断点共 35 组布局，无横向溢出；运行无 pageerror；页面没有外部 HTTP 请求。
- 切换 CNY / USD、趋势模式和主题时保留图表实例 ID，setOption 更新数据；USD 首周支出为 444.44。
- SVG 分类柱形真实指针点击进入“居住”筛选；周数据按钮进入对应期间明细，重置恢复全月。
- 离开图表页面后旧实例释放；ResizeObserver 将图表宽度更新为容器实际宽度。
- 动态开启 prefers-reduced-motion 后图表 animation=false、卡片 CSS animation=none，交互仍可用。
- 分析环图与 5 项分类图例共享数据与配色；深浅主题和移动图表已截图检查。
- 视觉检查发现并修复原型主题背景 / 正文继承问题；趋势模式按钮在切换后恢复键盘焦点。

进度仍是设计待验收，M4-DASH / M4-RESP / M7-PERF 增补了 ECharts、动效和生命周期的实施验收标准。未测真实生产帧率、Next.js 图表 chunk、SSR 性能；这些仍属于实施阶段。
