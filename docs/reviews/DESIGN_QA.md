## v0.3 · 主题色与深浅模式复核

日期：2026-10-02 · 执行者：Claude Code · 环境：Playwright 1.56 + Chromium（headless），以 file:// 离线打开原型。作者自检，不代替 G0。

根据用户要求，原型新增外观设置：浅色 / 深色 / 跟随系统三种显示模式，7 个预设主题色和自定义色。实现位于 [theme.js](../ui/theme.js)，令牌与面板在 [index.html](../ui/index.html)。规范见 UI_SPEC §2.2，实现约束见 TECHNICAL_DESIGN §7.4。

| 检查 | 方法 | 结果 |
| --- | --- | --- |
| 模式解析 | 模拟系统浅 / 深色，分别切换跟随系统、浅色、深色 | 6 种组合均正确；跟随系统下切换系统外观，页面和图表即时更新；手动模式不受系统影响，提示文案同步系统当前值 |
| 图表换色 | 记录 ECharts 实例 ID 和 series 颜色 | 换色前后实例 ID 相同；收入 positive、支出蓝色随模式变化，不随主题色变化 |
| 对比度 | 读取实际渲染的计算样式：7 个预设 + 8 个极端自定义色（白、黑、纯黄、纯红、纯绿、纯蓝、浅天蓝、洋红）× 2 种模式 | 30 组全部 ≥4.5:1，覆盖主题色文字（surface / canvas / soft）、按钮文字、soft 底次级文字、侧栏文字 / 选中项 / 卡片 / 链接、品牌标记、侧栏焦点环 |
| 自定义输入 | #ff0000、非法值 #12、#6B4EFF | 红色自动生成 #D20000 / #FF7361，并提示接近错误色；非法值内联报错且不改变主题；紫色生成 #684AFB / #9896FF，预览显示 4.53:1 / 4.75:1 |
| 持久化 | 刷新页面、恢复默认 | 刷新后保持手动深色 + 自定义色；恢复默认后为跟随系统 + 青绿；localStorage 不可用时仅提示本次生效 |
| 键盘与焦点 | 打开面板、方向键、Esc、移动“更多 → 外观” | 打开时焦点在当前模式；方向键切换主题色并即时预览；Esc 关闭后焦点回到入口（桌面“外观”按钮、移动“更多”按钮） |
| 响应式 | 7 视图 × 5 断点 × 浅 / 深色，外加外观面板 | 80 组检查无横向溢出；360px 为底部 sheet |
| 运行错误与网络 | pageerror、console error、请求记录 | 0 错误；无外部 HTTP 请求 |
| 进度数据 | progress validate | 35 任务、无环依赖、生成文档一致 |
| Mermaid | Mermaid 11 在浏览器中 parse + render USER_FLOWS、TECHNICAL_DESIGN、DELIVERY_PLAN 的全部 13 张图 | 全部通过，含新增 F10 两张图 |

自检中发现并修正：

- 原默认青绿 #087F72 作为文字放在 soft 底（标签、选中态）上仅约 4.2:1，调整为 #07766A（4.73:1）；松绿预设同理调整。
- 深色模式 soft 混合比例由 18% 降到 15%：使用近白或纯黄自定义色时，soft 底上的次级文字原先会降到 4.23:1。
- 收入金额和收入图例原先使用主题色，改为固定 positive 色，避免主题色改成红色系时与支出混淆。预算超过 80% 时增加“⚠ 接近上限”文字，主题色与警告色接近时信息不丢失。
- 侧栏焦点环原先在深色侧栏上使用浅色模式主题色，对比度不足，改为使用深色模式主题色。
- 模式图标由字体字符改为内联 SVG，避免不同系统字体下大小不一。

本轮重新生成了 6 张原有截图，并新增 3 张外观截图。截图使用 reducedMotion 模式，避免动画帧不稳定。尚未在真实 Windows 高对比度（forced-colors）、Safari / Firefox 和真机上验证外观；这些属于 M4-THEME / M4-RESP。
